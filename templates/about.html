PROJECT OVERVIEW

About AuthGuard.

AuthGuard is a small educational web application created to demonstrate defensive controls related to authentication and session management.

Project objectives

  • Demonstrate secure password storage using password hashing.
  • Validate password complexity during registration.
  • Limit repeated failed login attempts with a temporary lockout.
  • Protect form submissions with CSRF tokens.
  • Configure session cookie attributes and security response headers.
  • Record authentication events for basic monitoring.

Technology used

FrontendHTML / CSS / JS
BackendPython Flask
DatabaseSQLite
Password securityWerkzeug
RuntimeLocalhost
Scope: This project demonstrates selected authentication protections. It is not a full penetration-testing scanner, and the demo lockout policy is intentionally short for classroom demonstration.
